# ambient — Swift twin: `Mary/Sources/MaryAmbient`

What a turn is for, and what Mary already knows is in front of the person. Swift builds that knowledge
from the accessibility tree in tiers; on MaryOS the desktop simply says which app and window are in
front, over the same socket Spotlight uses (PORTING.md 9).

Status: **skeleton**. The nine `AmbientIntent` shapes and the `AmbientSignal`s that decide them, with
their Swift raw values; `ma_focus` declares the desktop-reported context. No router yet. Prefix `ma_`.
